# KYIVSPETSBLOK Website

Corporate one-page bilingual website for the academic project of **KYIVSPETSBLOK**.

## Structure

- `index.html` — main page markup
- `style.css` — styles and responsive layout
- `app.js` — JavaScript logic built with classes (`TranslationService`, `NavigationMenu`, `WebsiteApp`)
- `assets/` — logo and images

## Features

- Bilingual interface: Ukrainian / English
- Corporate visual style
- Responsive layout for desktop and mobile devices
- Static corporate network map image
- Object-oriented JavaScript structure for easier maintenance

## Launch

Open `index.html` in a browser.

## Note

This website is an academic demonstration project.
